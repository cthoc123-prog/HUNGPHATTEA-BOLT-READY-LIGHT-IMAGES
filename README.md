# Hung Phat Reimagined

HÙNG PHÁT WEBSITE REDESIGN (LUXURY BRANDED HOUSE)

Redesign the frontend of the existing website https://hungphatea.com/.

This is not a new startup website. This is a redesign for a real company with 38 years of history, existing SEO, existing URLs, existing products, and an active ecommerce system.

The goal is to create a luxury Vietnamese tea and botanical brand website inspired by Aesop, Ippodo Tea, Muji, Apple, Hermès, and Blue Bottle.

Technical Requirement

Design this as a frontend rebuild, not a backend replacement.

Assume the existing ecommerce and SEO infrastructure will remain.

Create a production-quality UI that can later be connected to Sapo or Next.js without redesigning the interface.

The website should feel like Ippodo Tea meets Aesop, while remaining deeply Vietnamese and rooted in Bảo Lộc craftsmanship.
